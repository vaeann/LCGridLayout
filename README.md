# LCGridLayout

> **本仓库是 [Kan9e/LCGridLayout](https://github.com/Kan9e/LCGridLayout) 的二次开发分支（fork）。**
> 自 2026-11-08 起由 [@vaeann](https://github.com/vaeann) 维护，按 **AGPL-3.0** 分发。
> 与上游的差异见 [docs/FORK.md](docs/FORK.md)；要改代码先看 [docs/DEVELOPING.md](docs/DEVELOPING.md)。
> 下载用[本仓库的 Releases](https://github.com/vaeann/LCGridLayout/releases)，上游原版在[上游仓库](https://github.com/Kan9e/LCGridLayout/releases)。

给 **LiveContainer 3.8.0 及以上**（含 3.8.2 / 3.8.11 等 nightly）的宿主侧 UI 插件：把“我的应用”列表换成桌面式图标网格。

**下载**：[Releases](https://github.com/vaeann/LCGridLayout/releases) · **许可**：[AGPL-3.0](LICENSE) · **构建**：本仓库改由 GitHub Actions 出包，见[构建](#构建)

## 功能

- 4 / 5 列切换，图标名称可显示或隐藏
- 搜索应用、下拉刷新
- **长按图标**（0.3 秒，带触感）：
  - 按住后**移动** → 直接拖动排序，松手保存；顺序会持久化，原生列表若已选自定义排序也会同步
  - 按住后**保持不动约 0.35 秒** → 不用松手，菜单就会弹出（隐藏 / 卸载）
  - 长按后**很快松手** → 同样弹出菜单
- **底部计数条**：显示“共 N 个 App”；连续点 3 次（与原生一致）并通过面容/密码认证后，隐藏应用会出现在网格末尾，重启 LiveContainer 自动上锁
- 加锁应用显示锁标，点按后仍由 LiveContainer 弹原生解锁
- 自定义背景：从系统相册选图（`PHPicker`，不需要相册权限），最长边压到 2200px 的 JPEG 存在插件自己的目录，重启保留，可随时移除
- **右下角一个悬浮按钮，两种手势**：点一下切布局（图标显示目标模式——网格时是列表图标，原生时是宫格图标），**长按**打开网格设置面板
- 原生模式下长按只给「切换到宫格布局」+ 取消（网格设置在那种状态下改也看不见）
- 顶部与原生一致：`App` 大标题（34pt 粗体、左 16pt）+ 默认收起的搜索栏，下拉才展开
- 网格模式下 LiveContainer 自己的搜索框会被隐藏，双击顶部空白也不会把它叫出来
- **顶部工具栏已移除**：原来「恢复原生 / 网格设置」那一行连同 40pt 占位一起删掉，网格紧贴导航栏
- 两个按钮都夹在 tab bar 上方 14pt，不会压住标签栏
- 图标点击走 `livecontainer-launch?bundle-name=<文件夹名>`，加锁、JIT、容器选择仍由 LiveContainer 原生逻辑处理

## 环境要求

- LiveContainer **3.8.0 及以上**（3.8.0 / 3.8.2 / 3.8.11 / 3.9.x 均按同一套 API 适配；低于 3.8.0 会直接退出，不会乱盖 UI）
- iOS 15+，arm64
- 已导入 JIT-Less 证书（用于给 dylib 重签）

## 安装（摘要）

1. LiveContainer → **Tweaks** → 全局根目录 → **Import Tweak** 导入 `LCGridLayout_v24.dylib`
2. 点 Tweaks 页的签名按钮，用当前证书重签
3. Settings 底部连点版本号 5 次 → Developer Settings → 打开 **Load Tweaks to LiveContainer Itself**
4. 完全退出 LiveContainer，重新打开

细节、排错、回退和删除见 [docs/INSTALL.md](docs/INSTALL.md)。

## 回退与删除

1. 网格右下角点「原生布局」
2. 关掉 Developer Settings 里的宿主注入开关并重启，插件不再加载
3. 把 dylib 改名成 `*.disabled`（上游 TweakLoader 会跳过）或直接在 Tweaks 页删除
4. 可选：删除 `Library/Logs/LCGridLayout.log` 与 `Library/Application Support/LCGridLayout/`

全程不需要修改 IPA。

## 技术说明

- **挂载方式**：在宿主的“我的应用”页上 `addChildViewController` 叠一层铺满宿主视图的覆盖层（`hitTest` 穿透），内容按安全区排版；标签栏毛玻璃下方也由覆盖层挡住。
- **不 hook**：不 swizzle 任何方法，不抢 key window，不挂手势，因此能和 LCFloatingMenu 这类插件共存。
- **发现宿主**：启动后前 1.2 秒按 30ms、之后按 0.1 秒轮询；启动动画期间（前台非活跃）就开始挂载，导航标题还没写入时也接受宿主页。
- **图标**：首帧直接读 `.app` 内的 `AppIcon*.png`，之后用宿主自己的 `generateIconForBundleURL:style:hasBorder:` 逐个替换为主题图标，不阻塞主线程。
- **日志**：`Library/Logs/LCGridLayout.log`，上限 128 KB，超出重写；设置里可一键导出。

## 当前状态

- v9 已在 LiveContainer 3.8.0 / iPhone（iOS 26）实测：冷启动挂载约 28–34 ms、切标签无闪烁、自定义背景持久化、图标启动正常
- v10 起版本门禁改为「>= 3.8.0」；v11 增长按菜单与拖动排序，v12 加隐藏应用解锁，待真机验证
- 未验证：iPad / 横屏、多任务并发、其他 iOS 版本、LiveContainer 3.8.0 之外的其他版本

## 构建

> **本仓库的常规路径是 GitHub Actions**：Actions → **Build dylib** → Run workflow。
> 产物在 artifact 里；勾选 `create_release` 会同时发 Release。Windows 上不需要装 Xcode。
> 下面的本地脚本只在装有完整 Xcode 的 macOS 上可用。

```bash
bash scripts/build.sh    # 产物 dist/LCGridLayout_v<N>.dylib，完整日志 logs/build.log
```

脚本要求完整 Xcode（`/Applications/Xcode.app`）及其 iPhoneOS SDK，只在编译、签名校验、Mach-O 平台/架构/依赖检查全部通过后才复制产物；任一步失败即退出。

## 版本与文件命名

`VERSION` 文件里的序号决定产物文件名：`scripts/build.sh` 生成 `dist/LCGridLayout_v<N>.dylib`，并把 `dist/LCGridLayout.dylib` 更新为指向最新版的符号链接。运行日志会打印实际加载的文件名：

```
Host gate passed: LiveContainer 3.8.11 (>= 3.8.0); LCGridLayout_v10.dylib loaded; no method hooks installed
```

装到设备时 Tweaks 里只能保留一个 `LCGridLayout*`：多个副本会被同时加载。

## 已知限制

- 依赖 LiveContainer 3.8.x 的界面结构（标题、Tab、TweakLoader 行为）；更大版本变动时可能需要跟进
- 全局 Tweaks 只有 1 个条目时，3.8.0 上游的 `TweakLoader` 会跳过加载，需要至少两个条目
- ad hoc 签名无效，必须在 LiveContainer 内用当前证书重签
- iPad / 横屏下 4–5 列会明显留白（单元格宽度按屏宽均分）
- `builtinSideStore` 这类虚拟应用没有 `.app` 文件夹，不会出现在网格
- 网格按名称排序，不复用原生列表的自定义排序
- 自定义背景固定叠 35% 黑色遮罩，暂不提供透明度调节
- 隐藏 / 卸载是直接改文件，LiveContainer 的内存模型不会立刻更新；操作后建议完全退出重开一次
- 卸载不会清理钥匙串里的旧条目（原生卸载会，我们无法调用该 Swift 接口）
- 卸载只对非共享应用开放；共享应用请在原生列表操作
- 多任务里正在运行的应用不建议卸载，先关闭再操作
- 要从网格启动隐藏应用，需要关闭 LiveContainer 的「严格隐藏」：该模式下 LC 的 URL 启动不会查找隐藏列表（原生列表能启动，是因为它直接调用内存模型，插件调不到）。关闭后 LC 仍会用 Face ID 保护隐藏应用
